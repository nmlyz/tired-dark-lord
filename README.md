A tiny program that writes a 100-word villain monologue to a text file.

A lich whose phylactery turned out to be a teapot receives a visitor, pours
the tea, and explains — between the lines — why eternity has started to feel
very long. The monologue is spoken word: short sentences, pauses, small
deflections, and a last line that lands.

## Run

```sh
python3 main.py
```

This writes the monologue to `/output/entry.txt` (UTF-8, mode 0644).
Standard library only; running it twice produces byte-identical output.
